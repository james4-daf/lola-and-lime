# Lola & Lime

Marketing site for [@lolaandlime](https://www.instagram.com/lolaandlime/) — vintage glass, decor, barware, uranium glass, and Hawaiian shirts from the Ontario flea circuit.

## Dev (Vite marketing site)

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Shopify theme

Online Store 2.0 theme lives in [`theme/`](./theme/). From that folder, with Shopify CLI + a Partner development store:

```bash
cd theme
shopify theme dev --store YOUR_STORE.myshopify.com
```

See the setup guide in the project store: `docs/shopify-setup.md`.
